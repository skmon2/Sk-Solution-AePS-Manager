Support

Sk Solution AePS Manager

Thank you for using Sk Solution AePS Manager.

Before Requesting Support

Please try the following:

1. Restart the application.
2. Check that you are using the intended version.
3. Note the steps that caused the problem.
4. Write down the exact error message, if any.
5. Back up important records before attempting troubleshooting.

Report a Bug

Visit the official GitHub repository:

https://github.com/skmon2/Sk-Solution-AePS-Manager

If GitHub Issues are enabled, you may submit a report describing:

- Your application version.
- Your Windows version.
- The steps to reproduce the issue.
- The expected and actual result.
- A screenshot with private information removed, if useful.

Security and Privacy

Never include passwords, OTPs, API keys, license secrets, customer details, or confidential transaction records in a public issue.

For suspected security vulnerabilities, do not publish exploit details or sensitive information publicly. Contact the software maintainer through an appropriate private channel.

Important

This repository is the official project page. A response time or support service level is not guaranteed unless separately stated by the maintainer.
