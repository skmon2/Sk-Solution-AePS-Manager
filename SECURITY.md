Security Policy

Sk Solution AePS Manager

We take the security of Sk Solution AePS Manager seriously.

Supported Versions

Version| Security Updates
1.5.1| Please contact the maintainer to confirm current support status.

Reporting a Vulnerability

If you discover a possible security vulnerability, please avoid posting sensitive technical details publicly.

Visit the official repository:

https://github.com/skmon2/Sk-Solution-AePS-Manager

If GitHub private vulnerability reporting is enabled, use that feature. Otherwise, contact the maintainer through a verified private contact channel.

What to Include

Please provide, where safe and appropriate:

- The affected application version.
- A brief description of the issue.
- Steps to reproduce the issue without using real customer data.
- Potential impact and any suggested mitigation.

Protect Sensitive Information

Never include passwords, OTPs, API keys, license secrets, personal customer information, or confidential transaction records in a public report.

Response and Disclosure

The maintainer should review reports and coordinate any public disclosure after an appropriate fix is available. No response time is guaranteed unless separately announced.

---

This policy describes a reporting process; it does not guarantee that every version is actively maintained.
