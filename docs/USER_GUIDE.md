Sk Solution AePS Manager — User Guide

Version: 1.5.1
Platform: Windows

1. Introduction

Sk Solution AePS Manager is a Windows application for digital transaction and record management.

2. Installation

1. Download the installer from the "official GitHub Releases page" (https://github.com/skmon2/Sk-Solution-AePS-Manager/releases/latest).
2. Open the downloaded setup file.
3. Follow the instructions displayed by the installer.
4. Launch Sk Solution AePS Manager after installation.

Only install software obtained from a trusted, official source.

3. Dashboard

The dashboard provides an overview of transaction activity and business records. The information displayed may depend on your application configuration and stored data.

4. Main Menu

Available sections may include:

- Dashboard
- Transactions
- Reports / Export
- Daily Closing
- PDF Auto Import
- Account / License
- Profile
- Help & Support

5. Transaction Records

Review transaction details carefully before relying on them for business reconciliation. Check the transaction status and amount against the relevant service records.

6. Reports and Daily Closing

Use the available reporting and daily-closing features to review records. Keep backups of important business information.

7. Account and License

Use the Account / License section to review the license information and options shown in your installed application. Confirm the plan and terms before making a payment.

8. Updates

Use the Check for Updates option, if available, to check whether a newer version is available. Download updates only from the official GitHub Releases page.

9. Data Safety

- Keep your Windows account and application access secure.
- Never share passwords or OTPs.
- Do not publish customer information, transaction records, API keys, or other confidential data.
- Keep secure backups of important records.

10. Troubleshooting

If the application does not open or a feature does not work:

1. Restart the application.
2. Check whether you are using the intended version.
3. Keep a copy of any error message, without exposing private customer information.
4. Contact the software maintainer through the official repository.

11. Support

Visit the "Sk Solution AePS Manager GitHub repository" (https://github.com/skmon2/Sk-Solution-AePS-Manager).

---

This guide provides general instructions. Actual features may vary by installed version and configuration.
